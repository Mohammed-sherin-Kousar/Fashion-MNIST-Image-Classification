# Fashion-MNIST Image Classification using CNN

##  Project Overview

Developed a **Convolutional Neural Network (CNN)** using **Python, TensorFlow, and Keras** to classify Fashion-MNIST images into **10 clothing categories**.

This project demonstrates an end-to-end deep learning workflow, including **data preprocessing, image augmentation, CNN model development, regularization, training, and model evaluation**.

##  Objective

To build and evaluate a CNN model capable of accurately classifying grayscale clothing images into their respective categories.

##  Technologies Used

* **Python**
* **TensorFlow & Keras**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **Scikit-learn**
* **Google Colab**

##  Key Steps

* Loaded and explored the Fashion-MNIST dataset.
* Normalized pixel values and reshaped images for CNN input.
* Split the data into training and validation sets.
* Applied **data augmentation** using rotation, zoom, and image shifting.
* Built a CNN using convolutional, pooling, and dense layers.
* Applied **L2 regularization and Dropout** to reduce overfitting.
* Developed and compared CNN models **with and without Dropout**.
* Evaluated model performance using **Accuracy, Precision, Recall, F1-Score, and Confusion Matrix**.
* Visualized training and validation performance.

  ##  Model

* Built a **Convolutional Neural Network (CNN)** using TensorFlow and Keras.
* Used **Conv2D and MaxPooling** layers for image feature extraction.
* Used **Flatten and Dense layers** for classification.
* Applied **L2 regularization** to help reduce overfitting.
* Applied **Dropout (50%)** for regularization.
* Developed a second CNN **without Dropout** to compare model performance.
* Used **Softmax** output for classification into 10 Fashion-MNIST categories.

##  Dataset

**Fashion-MNIST** contains **70,000 grayscale images (28×28 pixels)** across 10 categories:

T-shirt/top | Trouser | Pullover | Dress | Coat | Sandal | Shirt | Sneaker | Bag | Ankle boot
